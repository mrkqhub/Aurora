# Первое внедрение

Обработка для адаптации библиотеки под конкретный проект.
При внедрении Aurora содержит префиксы `аа_` и суффиксы `(АА)` в именах и синонимах объектов.
Обработка позволяет заменить их на принятые в вашем проекте значения.

## Запуск

Откройте обработку `аа_ПервоеВнедрение.epf` из папки релиза.

## Параметры

| Параметр | Описание |
|---|---|
| **Путь исходных файлов** | Каталог с файлами конфигурации (выгрузка в XML) |
| **Путь сохранения** | Каталог куда будут сохранены измененные файлы |
| **Заменять префиксы/суффиксы** | Включает замену на значения ниже |
| **Префикс** | Новый префикс для имен объектов (по умолчанию `аа_`) |
| **Суффикс** | Новый суффикс для синонимов объектов (по умолчанию `(АА)`) |

## Порядок работы

1. Выберите каталог с исходными файлами или выгрузите конфигурацию в файлы через Конфигуратор
2. Укажите путь к выгруженным файлам в поле **Путь исходных файлов**
3. Укажите **Путь сохранения** — куда записать результат
4. Если нужно заменить префиксы и суффиксы — включите флаг и задайте нужные значения
5. Нажмите **Адаптировать конфигурацию**
6. Загрузите измененные файлы обратно в Конфигуратор

!!! tip "Если аффиксы не нужны"
    Оставьте поля префикса и суффикса пустыми — обработка просто удалит `аа_`/`(АА)` из имен и синонимов объектов.
