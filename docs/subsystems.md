# Готовые подсистемы

## Предопределенные значения

Подсистема для управления константами и настройками конфигурации.

### Назначение

Позволяет описывать константы и настройки прямо в коде, а пользователям —
заполнять их значения в удобном интерфейсе без доработки конфигурации.

### Возможности

- **Описание в коде** — константы и настройки объявляются программно
- **Одиночные значения и списки** — настройка может хранить как одно значение, так и произвольный набор
- **Иерархическая группировка** — настройки организуются в дерево групп
- **Два интерфейса**:
    - Форма администратора — полный список всех значений для управления подсистемой
    - Пользовательская форма — привычный интерфейс в стиле типовых решений 1С для заполнения настроек
