# Подсистема предопределенных значений

## Реализация

Хранение значений реализовано с использованием иерархического плана видов характеристик `аа_ПредопределенныеЗначения`.

Получение значений происходит через модуль повторного использования. При этом изменение любой настройки автоматически сбрасывает кэш — перезапуск сеанса для получения актуальных значений не требуется.

### Интерфейс

Реализовано две формы списка предопределенных значений.

#### Форма списка

Предполагается использование администратором подсистемы. Все группы и элементы ПВХ доступны в виде дерева. На форме реализована команда `Актуализировать`, которая синхронизирует состав ПВХ в пользовательском режиме с описанием в коде.

#### Пользовательская форма

Форма `ФормаНастроек` предназначена для вывода привычного пользователю интерфейса с настройками. Элементы добавляются на форму программно в зависимости от текущего состава ПВХ `аа_ПредопределенныеЗначения`. Для открытия формы из командного интерфейса реализована команда ПВХ `НастройкиИПредопределенныеЗначения`.

### Ключевые реквизиты ПВХ

| Реквизит | Тип | Редактируемый | Описание |
|---|---|:---:|---|
| `Наименование` | `Строка(150)` | ❌ | Наименование группы или элемента |
| `ТипЗначения` | `ОписаниеТипов` | ❌ | Типы значения, доступные к выбору |
| `Идентификатор` | `Строка(333)` | ❌ | Уникальное имя для обращения к элементу в коде |
| `Описание` | `Строка(1024)` | ❌ | Описание группы или элемента. Рекомендуется к заполнению — выводится в том числе на пользовательской форме |
| `Комментарий` | `Строка(1024)` | ✅ | Выводится только на форме редактирования элемента |
| `СписокЗначений` | `Булево` | ✅ | Определяет поведение элемента: одно значение или несколько |
| `ОдноЗначение` | `Булево` | ❌ | Определяет возможность установки флага `СписокЗначений` в пользовательском режиме |
| `УровеньИерархии` | `Число(10, 0)` | ❌ | Служебный реквизит для корректного отображения на пользовательской форме. Рассчитывается автоматически при актуализации |


### Табличные части ПВХ

Вне зависимости от флага `СписокЗначений` значения хранятся в табличной части `Значения`.
Программно обеспечено наличие минимум одной строки ТЧ для исключения ошибки незаполненного значения.

| Реквизит | Тип | Описание |
|---|---|---|
| `Значение` | `Характеристика.аа_ПредопределенныеЗначения` | Значение настройки или константы |

## Применение в разработке

### Подключение

Установите функциональную опцию `аа_ИспользоватьПредопределенныеЗначения`
_(Использовать предопределенные значения (АА))_.

### Объявление значений

Заполнения списка групп и элементов предопределеннх значений происходит в процедуре `ЗаполнитьПредопределенныеЗначения` общего модуля `аа_ПредопределенныеЗначенияПереопределяемый`.

#### Добавление группы

Для добавления новой группы следует использовать функцию `аа_ПредопределенныеЗначения.НоваяГруппа`.

| Параметр | Тип | Описание |
|---|---|---|
| `ОписаниеПредопределенных` | `ТаблицаЗначений` | Таблица с описанием предопределенных значений |
| `Наименование` | `Строка(150)` | Наименование группы |
| `Идентификатор` | `Строка(333)` | Уникальный идентификатор группы |
| `Описание` | `Строка(1024)` | Описание группы |
| `ИдентификаторРодителя` | `Строка(333)` | Идентификатор родительской группы. Если заполнен — группа создается в иерархии родителя |

#### НовоеЗначение

Для добавления нового элемента следует использовать функцию `аа_ПредопределенныеЗначения.НовоеЗначение`.

| Параметр | Тип | Описание |
|---|---|---|
| `ОписаниеПредопределенных` | `ТаблицаЗначений` | Таблица с описанием предопределенных значений |
| `Наименование` | `Строка(150)` | Наименование элемента |
| `Идентификатор` | `Строка(333)` | Уникальный идентификатор элемента |
| `ТипЗначения` | `ОписаниеТипов` | Доступные типы значений |
| `Описание` | `Строка(1024)` | Описание элемента |
| `ИдентификаторРодителя` | `Строка(333)` | Идентификатор родительской группы. Если заполнен — элемент создатся в иерархии родителя |

#### Примеры использования
```bsl
Процедура ЗаполнитьПредопределенныеЗначения(ПредопределенныеЗначения) Экспорт
	
	// Добавление группы.
	НоваяГруппа = аа_ПредопределенныеЗначения.НоваяГруппа(
		ПредопределенныеЗначения,
		"Настройки подсистемы продажи", 								// Наименование группы.
		"Продажи", 														// Уникальный идентификатор группы.
		"Настройки и константы, используемые в блоке ""Продажи"""); 	// Понятное пользователю описание группы.
	
	// Добавление значения.
	НовоеЗначение = аа_ПредопределенныеЗначения.НовоеЗначение(
		ПредопределенныеЗначения,
		"Организация по умолчанию", 											// Наименование элемента.
		"ПродажиОрганизацияПоУмолчанию", 										// Уникальный идентификатор элемента.
		Новый ОписаниеТипов("СправочникСсылка.Организации"), 					// Доступные типы значений.
		"Организация, подставляемая по умолчанию во все документы продажи", 	// Понятное пользователю описание настройки.
		"Продажи"); 															// Идентификатор группы - родителя.
	
	// Часть реквизитов недоступна из конструктора и устанавливается после создания.
	НовоеЗначение.ОдноЗначение = Истина;
	
КонецПроцедуры
```

### Получение значений

Для получения значений используются:

| Контекст | Функция |
|---|---|
| Сервер | `аа_ПредопределенныеЗначения.ЗначенияНастройки(Идентификатор)` |
| Клиент | `аа_ПредопределенныеЗначенияКлиент.ЗначенияНастройки(Идентификатор)` |

!!! note "Возвращаемое значение"
    Обе функции всегда возвращают массив с минимум одним элементом.
    Значение элемента может быть пустым.

```bsl
// Получение значений на сервере.
аа_ПредопределенныеЗначения.ЗначенияНастройки("ПродажиОрганизацияПоУмолчанию");

// Получение значений на клиенте.
аа_ПредопределенныеЗначенияКлиент.ЗначенияНастройки("ПродажиОрганизацияПоУмолчанию");
```
