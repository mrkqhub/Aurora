# Aurora

Проектная библиотека готовых решений для 1С, ускоряющая старт разработки.

## Зачем это нужно

При внедрении проектов на 1С одни и те же задачи решаются снова и снова.
Aurora собирает эти решения в готовые подсистемы, которые можно подключить
и использовать сразу.

## Что уже есть

| Подсистема | Статус |
|---|---|
| [Предопределенные значения](subsystems.md#Предопределенные-значения) | ✅ Готово |
| Встроенный инструментарий разработчика | 🚧 В разработке |
| Программное изменение форм | 🚧 В разработке |

## Быстрый старт

!!! tip "Начало работы"
    Перейдите в раздел [Первое внедрение](firstImplementation.md) чтобы подключить библиотеку к своему проекту.
